# Decisions and ideas

The owner works across more than one Claude account. This folder is the shared memory: **read it first in every session**, and add to it whenever the owner decides something or a good idea comes up. Newest first within each file.

- `DECISIONS.md`: what the owner has decided, and why. Treat it as standing instructions.
- `IDEAS.md`: ideas worth keeping that aren't decided yet.
- `CODEBASE.md`: what each part of the three repos is, live, old map or history; check it before building anything.
- `NOW.md`: where the work stands right now, and what's next. Update it at the end of every session.
